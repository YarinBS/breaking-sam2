Metrics in Breaking SAM 2

What each number means, how it is calculated, and how to read it. Every definition matches src/metrics.py; the numbers combined across clips are in Section 4 of docs/METRICS.md. Thresholds come from configs/benchmark.yaml.

Notation 1. Per-frame metrics 2. Per-clip summary 3. Failure & recovery 4. Reading them together

Notation

For one video frame $t$:

  • $G_t$ is the ground-truth (GT) mask: the set of pixels that belong to the target.
  • $P_t$ is the predicted mask: the set of pixels the pipeline labels as the target.
  • $|A|$ is the number of pixels in the set $A$.
  • $\mathcal{T}$ is the set of annotated frames. The code allows sparse GT (the protocol planned every 5th–10th frame), but all four datasets of the benchmark annotate every frame, so here $\mathcal{T}$ contains every frame.

All masks are binary. For indexed masks (DAVIS, M3-VOS, VOST, VOT), --object-id k keeps only pixels with value $k$; without it, every nonzero pixel is foreground.

Missing annotations are skipped. A frame without a GT file is never treated as an empty mask. Every per-frame metric is computed only for $t \in \mathcal{T}$.

1. Per-frame metrics

These are saved for every annotated frame in metrics/frame_metrics.csv.

1.1 Region similarity J (Jaccard index / IoU)

$$J_t = \frac{|G_t \cap P_t|}{|G_t \cup P_t|}, \qquad J_t = 1 \text{ if } G_t = P_t = \varnothing$$

Meaning. The share of correct pixels, out of all pixels that either mask calls "target". It measures how well the two regions overlap.

$J$Typical reading
$\ge 0.8$Good segmentation; errors mostly at the edges.
$0.5$ – $0.8$Target found, but a large part is missing or extra.
$< 0.5$Counted as a failed frame by the failure rule (Section 3).
$0$No overlap: target lost, or a different object is tracked.
  • $J$ is stricter for small and thin objects. A few pixels of shift destroy most of the overlap of a thin liquid stream; a large object hardly changes.
  • If the target leaves the frame ($G_t = \varnothing$), $J_t = 1$ only when the prediction is also empty; any leftover prediction gives $J_t = 0$. This is how false-positive persistence shows up.

1.2 Boundary accuracy F

$F$ checks whether the contours of the two masks are in the same place, allowing a small distance error.

Step 1 — boundary maps

A pixel is a boundary pixel if its value differs from its east, south, or south-east neighbour (the DAVIS seg2bmap rule). Call the maps $\partial G_t$ and $\partial P_t$. Mask edges touching the image border are not counted.

Step 2 — tolerance radius

$$r = \max\!\left(1,\; \left\lceil \tau \sqrt{H^2 + W^2}\, \right\rceil\right) \text{ pixels}, \qquad \tau = 0.008$$

For DAVIS 480p ($854\times480$): $r = \lceil 0.008 \cdot 979.7 \rceil = 8$ px. For 1080p: $r = 18$ px. The radius grows with image size, so $F$ is comparable across resolutions.

Step 3 — precision, recall, F

Let $D_r(\cdot)$ be dilation with a disk of radius $r$ ("everything within $r$ pixels").

$$\text{Precision}_t = \frac{|\partial P_t \cap D_r(\partial G_t)|}{|\partial P_t|}, \qquad \text{Recall}_t = \frac{|\partial G_t \cap D_r(\partial P_t)|}{|\partial G_t|}$$ $$F_t = \frac{2\,\text{Precision}_t\,\text{Recall}_t}{\text{Precision}_t + \text{Recall}_t}$$

Special cases: both boundaries empty → $F_t = 1$. Only one empty → $F_t = 0$.

  • Precision: how much of the predicted contour is near a real contour. Low precision = extra edges (background leaking in, noise blobs).
  • Recall: how much of the real contour is found. Low recall = parts of the outline are missing (e.g. a thin part cut off).
  • $F$ is the harmonic mean, so it is low when either is low. Precision 0.9 and recall 0.6 give $F = 2\cdot0.54/1.5 = 0.72$, below the simple average 0.75.
$F$ is sensitive to shape; $J$ is sensitive to area. A blob in the right place with a smooth, wrong outline can have a good $J$ and a poor $F$ — common for smoke, flames, and pouring liquid. When a mask lags behind a changing contour, $F$ usually drops before $J$.

1.3 Combined score J&F

$$(J\&F)_t = \frac{J_t + F_t}{2}$$

The standard single number in DAVIS-style papers. Use it for headline tables, but look at $J$ and $F$ separately to explain why a clip fails.

1.4 Signed area error

$$\text{AreaErr}_t = \frac{|P_t| - |G_t|}{|G_t|}, \qquad \text{undefined if } |G_t| = 0$$
  • $> 0$: prediction too large (over-segmentation, background takeover). $+1.0$ = twice the true area.
  • $< 0$: prediction too small (target shrinking or lost). $-1.0$ = empty prediction.
  • $\approx 0$ with low $J$: right size, wrong place — identity switch or drift to a similar object.

The sign gives the direction of the error, which $J$ cannot give.

1.5 Fragmentation

$$\text{Fragments}_t = \text{number of 8-connected components in } P_t$$

How many separate pieces the prediction has. A normal single-object mask gives 1 (not 0); an empty prediction gives 0.

Values above 1 mean the mask has split. This is not always an error: a pouring liquid or torn dough can really split. Compare with the GT before calling it "mask fragmentation". Stray blobs far from the target also raise this number.

1.6 Temporal IoU (prediction stability)

$$\text{TIoU}_t = \frac{|P_{t-1} \cap P_t|}{|P_{t-1} \cup P_t|}$$

Computed at annotated frames $t$, using the prediction of the frame just before, when it exists. It does not use GT.

  • High TIoU: the mask changes smoothly. Low TIoU: flicker or a sudden jump — but fast real motion also lowers it.
  • High TIoU + falling $J$: stable but wrong. The model keeps its old memory while the object changes (boundary lag, "stuck" mask).
  • Low TIoU + falling $J$: unstable; the target is lost suddenly.

2. Per-clip summary

metrics/summary_metrics.json aggregates the per-frame rows. Let the annotated frames be $t_0 < t_1 < \dots < t_{N-1}$. By the protocol, $t_0 = 0$ and $G_0 \ne \varnothing$.

FieldFormulaMeaning
initialization_j, _f, _j_and_fvalue at $t_0$First-frame mask quality. Low = initialization failed (bad box, or wrong Grounding DINO detection).
mean_j, mean_f, mean_j_and_f$\frac{1}{N}\sum_i J_{t_i}$ (etc.)Average over all annotated frames.
propagation_mean_j$\frac{1}{N-1}\sum_{i\ge1} J_{t_i}$Average $J$ without frame 0 — tracking quality only.
worst_j$\min_i J_{t_i}$The single worst moment.
mean_absolute_area_errormean $|\text{AreaErr}_t|$ where $|G_t|>0$Typical size error in either direction.
mean_fragmentsmean $\text{Fragments}_t$Typical number of mask pieces.

Keep initialization and propagation separate. For grounded_sam2, a Grounding DINO miss gives empty masks for every frame, so $J_{t_0}=0$ and the whole clip fails — but SAM 2 never tracked. Report these as detection failures, and compare propagation_mean_j only between runs whose initialization succeeded.

Caveat about means. Means are over annotated frames. In this benchmark every frame is annotated, so they are plain frame averages. With sparse GT that is denser near the event, the event would get more weight.

3. Temporal failure analysis

A mean hides when a clip breaks. The failure rule turns the $J$ curve into an event time. It was fixed before the experiments: failure_iou = 0.5, failure_consecutive = 2.

3.1 First failure

$$t_{\text{fail}} = \min\{\, t_i : J_{t_i} < 0.5 \;\text{and}\; J_{t_{i+1}} < 0.5 \,\}$$

In general: the first frame of the first run of $k=2$ consecutive annotated observations strictly below the threshold.

  • Two observations stop one noisy frame from counting as a failure.
  • If no run exists: first_failure_frame = null, failure_censored = true — the clip survived to the end.

3.2 Recovery

After a failure, recovery is the first frame of the first run of 2 consecutive annotated observations with $J \ge 0.5$ (searching after $t_{\text{fail}}$). It is only defined when a failure happened.

3.4 How to interpret failure times

  • Time to failure (research question i — which disruption breaks SAM 2 earliest): align clips by their event time and compare $t_{\text{fail}} - t_{\text{event}}$ in seconds (using the clip's fps).
  • Abrupt vs. gradual (question ii): look at the continuous $J$ curve near $t_{\text{fail}}$. A sharp drop with low TIoU is abrupt; a slow decline with high TIoU is gradual drift.
  • Recoverable (question ii): a recovery frame means SAM 2's memory found the target again; no recovery means a permanent error.
  • Censored clips did not fail. Do not replace their failure time with the clip length and average it — that makes the model look worse. Report the count of censored clips, or use a survival method such as a Kaplan–Meier curve.
  • Sampling: here every frame is annotated, so "two consecutive observations" are two consecutive frames at the clip's frame rate (VOST is sampled at 5 fps, so a failure shorter than 0.2 s can still be missed). With GT only every 10th frame, the failure would have to last about 10–20 frames, and a short failure between two annotated frames could be missed.
  • The binary rule is only a summary. Always keep and show the continuous curves (j_curve.png, f_curve.png, j_and_f_curve.png).

These patterns are hints for the human-authored qualitative labels, not automatic labels. Borderline cases need a second reviewer, as the protocol says.
